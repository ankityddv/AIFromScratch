# Resources

## LLM-Focused Fast track
1. [3Blue1Brown Neural Networks](https://www.youtube.com/watch?v=aircAruvnKk&list=PLZHQObOWTQDNU6R1_67000Dx_ZCJB-3pi)

    Time: ~4-5 hours

    Focus on ?

    * What is a neural network?
    * Weights
    * Parameters
    * Loss function
    * Gradient descent
    * Training

2. [Andrej Karpathy - Neural Networks: Zero to Hero](https://www.youtube.com/playlist?list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ)
    
    Lecture 1: Micrograd
    
    Time: ~2-3 hours
    
    Focus on ?

    * What is a neuron?
    * What is backpropagation?
    * Why training works?

3. [The Illustrated Transformer](https://jalammar.github.io/illustrated-transformer/?utm_source=chatgpt.com)

    This single article has probably taught more engineers transformers than any course.

    Focus on ?

    * Token
    * Embedding
    * Attention
    * Self-attention
    * Multi-head attention
    * Transformer block

4. [Karpathy - Let’s Build GPT](https://www.youtube.com/watch?v=kCc8FmEb1nY)

    This is where things start clicking.
    
    We’ll see:
    ```text
    tokens
    → embeddings
    → attention
    → transformer
    → next token prediction
    ```

    in actual code.

### At this point you’ll understand about 70-80% of the terminology.
